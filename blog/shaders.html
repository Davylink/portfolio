01 Complex Unit Shader INTERACTIVE / CUSTOMIZABLE MATERIAL C# | SHADER GRAPH +

Animated Team Color with Damage, Dirt and Dissolve Effects

A complete HDRP shader designed for use in all units which need Team Color, Animated Textures (conveyor belts, emission circuits, tank tracks...). It manages multiple core material properties, SSR transparency, dynamic team coloring, wear effects, real-time damage and animations for a wide range of Unity scenarios. It also features a vanishing effect for Fog Of War dissappearing and occlusion.

TECHNICAL BREAKDOWN

  • Full PBR pipeline integration for realistic material interaction.
  • Alpha-based SSR and depth buffer transparency, allowing clear views of the units interior.
  • Mask system for controlling multiple features like metallic/smoothness, height and ambient occlusion using RGBA channels.
  • Mask system for enabling wear, dirt and damage using RGBA channels.
  • Team color selection and emission RBG system allowing easy dynamic color changing of different model emissive parts.
  • Per-channel emission control with masked scrolling UVs and pulsing effects for interesting glowing effects.
  • Texture UV displacement for moving parts such as conveyor belts or tank tracks with speed controlled via script.
  • A dissolve-based appearance or disappearance effect, with controllable edge glow, for spawning or hidding effects.
